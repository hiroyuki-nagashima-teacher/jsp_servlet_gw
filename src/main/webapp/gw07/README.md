## 2. 作業3: 置き換え判断表

| 置き換え前 | 置き換え後 (JSTL/EL) | 理由 |
|---|---|---|
| JSP式による値の出力 | `${変数名}` または `<c:out value="${変数名}"/>` | JSP内にJavaコードを埋め込まず、簡潔かつ安全（エスケープ処理）に出力できるため。 |
| `out.print`による値の出力 | `<c:out value="${変数名}"/>` | スクリプトレットを一切使わずに、HTMLエスケープを伴う安全なテキスト出力をタグとして完結できるため。 |
| `if`文による単純な条件分岐 | `<c:if test="${条件}">...</c:if>` | 単一の分岐判定をHTMLのようなタグ構造でスマートに表現できるため。 |
| `if〜else if〜else`による複数分岐 | `<c:choose>`<br>`  <c:when test="...">...</c:when>`<br>`  <c:otherwise>...</c:otherwise>`<br>`</c:choose>` | Javaの `if-else` 制御構造を、HTMLのネストを汚すことなくタグのみで視覚的にわかりやすく記述できるため。 |
| `for`文による一覧表示 | `<c:forEach var="要素名" items="${コレクション}">` | コレクション（配列・Listなど）の全要素ループ処理を、インデックス制御用のJavaコードを書かずにループできるため。 |
| `for`文で番号を表示する処理 | `varStatus="status"` を指定し、 `${status.count}` を出力 | ループ内で手動でカウンタ変数をインクリメント（`i + 1`）する記述を排除し、バグの混入を防げるため。 |
| Mapのkeyとvalueを取り出す処理 | `<c:forEach var="entry" items="${Map変数}">`<br>`  ${entry.key} / ${entry.value}` | Mapの各エントリが `Map.Entry` として自動抽出され、JavaのkeySetなどのメソッドを使わずに簡単に参照できるため。 |

## 3. 作業4: タグ選択表

| やりたいこと | 使う構文・タグ | 理由 |
|---|---|---|
| 値を表示したい | `${変数名}` | 最も短くシンプルにスコープ変数の値を出力できるため。 |
| 値をタグ形式で表示したい | `<c:out value="${値}"/>` | 特殊記号（<, > 等）を自動でエスケープし、XSS（クロスサイトスクリプティング）を防止するため。 |
| 値を一時的に設定したい | `<c:set var="変数名" value="値"/>` | スコープオブジェクト（page等）に新しい変数をセットし、後続の処理で再利用可能にするため。 |
| 値を削除したい | `<c:remove var="変数名"/>` | 設定した変数をスコープから安全に破棄し、メモリ管理や条件初期化を行うため。 |
| 1つの条件だけ判定したい | `<c:if test="${条件}">` | 指定した条件が真（true）の場合のみ、タグで囲んだコンテンツを出力するため。 |
| 複数条件から1つを選びたい | `<c:choose>` / `<c:when>` / `<c:otherwise>` | 複数の排他的な条件（もし〜なら、そうでなければ）を表現し分けるため。 |
| 配列やリストを繰り返し表示したい | `<c:forEach var="要素" items="${配列等}">` | コレクション全体のデータを最初から最後まで順次繰り返し描画するため。 |
| 繰り返し中の番号を表示したい | `varStatus="status"` 内の `${status.count}` | 現在の処理回数（1始まりの連番）を自動管理された変数から安全に取得するため。 |
| Mapをキーと値で表示したい | `<c:forEach var="entry" items="${Map変数}">` | Mapの全Entryを取り出し、動的にキーと値を同時に出力するため。 |

## 4. 作業5: 発表メモ

* 私たちのグループでは、JSTLは
  [ **JSP内でよく使うJavaのロジック（条件分岐や繰り返し処理など）をHTMLライクなカスタムタグ形式で記述し、Javaコードの混入を防ぐ** ]
  のために使うものだと整理しました。
* ELは
  [ **スコープに保存されている変数の参照や値の表示、簡単な演算** ]
  を簡単に書くためのものだと整理しました。
* `c:if` は
  [ **else判定がなく、ある条件を満たす場合だけ特定のコンテンツを表示させたい** ]
  の場面で使いやすいです。
* `c:choose` は
  [ **「合格・不合格」や「評価A・B・C」のように、複数の条件によって出力を切り分けたい** ]
  の場面で使いやすいです。
* `c:forEach` は
  [ **配列やリスト、Mapなどのコレクションに格納されたデータを順にループして一覧表示したい** ]
  の場面で使います。
* `varStatus` は
  [ **ループ処理中に「何回目の繰り返しであるか」を表す連番（インデックスやカウント数）** ]
  を表示したいときに使えると分かりました。
* Mapを `c:forEach` で表示する場合、
  [ **変数に格納されたMap.Entryのプロパティ（key および value）** ]
  を使ってキーと値を取り出せます。
* スクリプトレットをJSTL/ELに置き換えると、
  [ **JSPのコードがHTMLタグの構造を保ったまま整理され、デザイナーとプログラマーの分業が容易になり、保守性と視認性が向上する** ]
  という利点があると考えました。
